Site pessoal de portfólio, com visual inspirado em terminal/cibersegurança (tema dark, tipografia monoespaçada, efeitos "cyber" nos cards).
🔗 Site no ar: https://maikom118.github.io/Meu_Site/
Sobre
Estudante do último ano de Sistemas de Informação, cursando cibersegurança pela Solyd. O site apresenta a trajetória, as tecnologias utilizadas e os projetos desenvolvidos.
Stack utilizada no site
HTML5 + CSS3 (puro, sem framework)
JavaScript vanilla
Fonte IBM Plex Mono / IBM Plex Sans (Google Fonts)
Formulário de contato integrado via Formspree
Hospedado no GitHub Pages
Seções
Sobre — apresentação e trajetória
Stack — tecnologias e ferramentas (Frontend & Mobile, Backend, Segurança, Automação)
Projetos — IAmed, CryptoLab e Gerador de Senhas, com links para os repositórios
Contato — formulário de e-mail + links para GitHub, LinkedIn e e-mail direto
Rodando localmente
Não há build nem dependências — é um único arquivo estático.
```bash
git clone https://github.com/Maikom118/Meu_Site.git
cd Meu_Site
# abra o index.html direto no navegador
```
Formulário de contato
O botão "enviar" da seção de contato envia a mensagem para o e-mail do Miguel através de um endpoint do Formspree. Para trocar o destinatário ou o endpoint, edite a constante `FORM_ENDPOINT` no `<script>` no final do `index.html`.
Deploy
O site é publicado automaticamente pelo GitHub Pages, a partir da branch `main`, pasta raiz (`/`). Qualquer alteração enviada (commit) no `index.html` é refletida no site em 1–2 minutos.
